# 课堂 INS 轨迹重构练习

## 本次实验要补全的 6 个关键步骤

请在 `reconstruct_motion.py` 中补全以下 6 处代码：

1. **角增量计算**：`delta_angle = ...`
2. **姿态更新**：`rotation = ...`
3. **机体系加速度转世界系**：`acc_world_before_gravity = ...`
4. **重力补偿**：`world_acc = ...`
5. **速度更新**：`velocity[k] = ...`
6. **位置更新**：`position[k] = ...`

## 推荐完成顺序

- 先对照 PPT 中“姿态更新”公式，完成步骤 1、2；
- 再对照“速度与位置更新”公式，完成步骤 3–6；
- 最后运行程序并观察轨迹结果。

## 运行方式

**默认（课堂必做）：仅用 IMU 的加速度与角速度自行解算姿态，执行全部 6 处填空**：

```bash
python reconstruct_motion.py
```

**可选对照：使用 IM948 内置四元数作为姿态**。这种模式跳过“角增量计算”和“姿态更新”两个填空，但仍须完成后 4 步：

```bash
python reconstruct_motion.py --quaternion
```

不显示窗口，仅保存结果：

```bash
python reconstruct_motion.py --no-show
```


## 注意事项

- 本实验的轨迹是**相对轨迹**，初始位置和初始速度都设为 0。
- 默认陀螺仪积分姿态可能产生漂移；可选 `--quaternion` 使用模块内置融合姿态进行对照，但仍需验证其坐标系和四元数约定。
- 程序中的滤波与简化零速修正是为了帮助观察，不属于基本 INS 公式本身。
